남녀별 상품당 코디 최소5장 데모 (2026-11-18)
최신 데이터: closet-demo-data-gender-five
시연 상품37개: 남성 코디용22개 / 여성 코디용15개. 각 상품은 기본 추천 범위에서 해당 성별 코디5장 이상.
해당 구성에서203개 상품→코디 연결, 중복 제외185개 코디 사진을 사용합니다.
전체 보존 묶음은 코디226장(공개 모델정보 확인224장, 기존 보류2장), 상품사진256장입니다.
새 코디사진22장/연결28개 추가. 모든 시연 상품을 소유한 경우를 위해 기존2코디에 유사상품2개 추가. 기존 상품34개 유지, 부족한3개 교체:
  hm_0876830003 → hm_0738488001 크림 라운드 니트
  hm_0608667002 → hm_0643308001 화이트 레이어드 원피스
  hm_0769777001 → hm_0542136001 블랙 슬리브리스 원피스

실행 (압축을 풀고 closet-capstone 폴더에서)
  python -m pip install -r requirements.txt
  python run_demo.py --data-root "../closet-demo-data-gender-five"
  http://127.0.0.1:8767/shop/#/mypage
포트가 사용 중이면 --retrieval-port 8945 --shop-port 8947 추가 후8947로 접속합니다.
종료 Ctrl+C. 사용자 기록은 코드 .local에 저장합니다. 이 공유 묶음에는 사용자DB가 없습니다.

시연 순서
1. 마이페이지 > 회원 정보에서 성별·연령대 저장. 로컬에서 가입정보를 재현하는 폼입니다.
2. 옷 추가 > 시연 상품 담기: 남성22개 / 여성15개 / 미입력37개.
3. 상의·하의·아우터·원피스·신발 탭에서 상품을 고르면 같은 화면 아래 코디5장이 표시됩니다.
   여유 후보가 있는 상품은 더 보기로 이어집니다. 여성 원피스2개도 각각5장입니다.
4. 코디를 열면 사진 속 다른 옷과 비교해 선별한 유사상품을 표시합니다. 이미 보유한 상품은 제외합니다.
5. 코디 둘러보기의 취향조사는 사진1~5개 선택 또는 건너뛰기. 가입 성별과 공개 모델정보 조건을 함께 적용합니다.

5장 조건은 상품별 지정된 시연 성별 + 기본 의류 범위 기준입니다.
일부러 의류 범위를 공용 등으로 좁히면 사진이 줄 수 있습니다.
성별을 바꿔도 기존 옷장/선택 이력을 삭제하지 않습니다. 새 시연 상품 목록만 해당 성별로 바뀝니다.
시연 배정은 상품 판매사의 공식 남녀 카테고리를 다시 판정한 것이 아닙니다.
같은 상품에 남녀 각각5장을 보장하는 구성도 아닙니다.

데이터/검수
- 무신사 전체8,626장 및41,943영역의 기존 특징값과 H&M105,100개 상품 특징값을 재사용했습니다.
- 새 모델 추론/재학습/전체 데이터 다운로드 없음. 추가 원게시물 조회와 사진 대조용 이미지 수집만 수행했습니다.
- 성별은 원게시물 model.gender를 사용합니다. 얼굴/체형으로 개인 성별을 추정하지 않습니다.
- 새로 연결한 사진은 원게시물 사진과 대조했습니다. 워터마크/여백 차이는 검수 근거에 기록했습니다.
- 실제 착용 상품의 동일성 검증이 아니라 종류·주 색상·실루엣이 유사한 대체 코디/상품 선별입니다.
  원피스 일부는 기장·레이스·넥라인, 하의는 워싱·핏, 신발은 밑창·장식이 다릅니다.
- 원피스4쌍은 기존 자동검색 기준0.55보다 낮은0.50~0.55 구간의 사진 검수 예외입니다.
  자동검색 전체 기준을 낮추지 않았으며 고정 시연 연결에만 적용했습니다.
- 실제 나이/게시자 성별 메타데이터의 독립적 정답 검증, 전체 추천 정확도 평가는 하지 않았습니다.
- 이전 데이터·이미지·DB·원본 코드 보존. 교체 상품도 과거 기록 조회를 위해 묶음 내부에 남겨둡니다.

공유 범위
- GitHub에는 closet-capstone 코드 폴더만 올립니다. 데이터는 별도 전달합니다.
- 실행에 모델/특징값 파일은 필요 없습니다. 이 묶음은 선별된 고정 연결로 시연합니다.
- 실행 중 무신사 원게시물 접속 없음. 증거 대조용 원격 사진은 공유 묶음에서 제외합니다.
- 실제 코디 정렬은 태그 기반입니다. 최신 Two-Tower 모델과 실연결/배포/GitHub 푸시는 하지 않았습니다.
- 취향 전달 API와 어댑터는 기존 계약 유지: team_bridge/README.txt.
