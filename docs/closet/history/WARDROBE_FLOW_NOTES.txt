2026-11-19 옷장 화면과 코디·유사상품 탐색 정리

시연 범위
- 등록된 입력상품 60개(MEN30/WOMEN30)와 검수된 코디/유사상품 연결을 사용합니다.
- 옷장에 임의 사진을 업로드해 신규 추천을 만드는 기능은 이번 캡스톤 데모 범위에 포함하지 않습니다.
- 상품 선택은 준비된 시연 상품을 보유 목록에 담는 기능입니다.
- 팀 검색 기능과 취향 전달 API 계약은 그대로 유지합니다.

변경한 흐름
1. 카테고리별 상품을 가로로 탐색하거나 전체 보기로 펼칩니다.
2. 상품을 누르면 같은 옷장 화면 아래 선택 상품 썸네일과 코디 목록을 표시합니다.
3. 코디를 누르면 배경을 흐리게 한 큰 창에서 코디 사진과 유사상품을 함께 보여줍니다.
4. 이전/다음, 아래 썸네일 또는 좌우 방향키로 현재 목록의 코디를 전환합니다.
5. 유사상품을 누르면 큰 사진으로 확인하고 '코디 사진으로' 돌아올 수 있습니다.
6. 닫기/Escape로 돌아오면 카테고리·선택상품·스크롤을 유지하고 원래 코디 버튼으로 초점을 돌립니다.

시연 창의 유사상품은 사진 비교용입니다. 코디 연결이 없는 상품을 옷장에 추가하는 버튼이나
팀 추천 서버가 필요한 상품 상세 페이지로의 이동은 이 창에서 제공하지 않습니다.
기존 직접 주소의 코디 상세와 코디 둘러보기 경로는 유지합니다.
보유상품 제외로 추천이 비면 '이미 보유하고 있어요'와 다른 코디 이동을 표시합니다.
이 문구는 기존 빈 추천 2개의 데이터를 새로 채웠다는 뜻이 아닙니다.
