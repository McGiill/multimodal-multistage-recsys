전체 전처리·자동 분류 연구 코드 보관

original_scripts/는 기존 작업 파일 9개를 수정 없이 복사한 기록입니다.
이 폴더는 run_demo.py가 실행하거나 불러오는 코드가 아닙니다.
데모만 실행하는 팀원은 이 폴더의 환경을 설치할 필요가 없습니다.

파일 역할
- run_musinsa_full_auto.py:기존 처리 결과를 재사용한 무신사 전체 자동 전처리
- verify_musinsa_full_auto.py:전처리 결과 자동 무결성 검사
- classify_musinsa_age_local.py:기존 전체 사진 특징과 텍스트 특징을 이용한 외관 후보 분류
- verify_musinsa_age_local.py:분류 산출물 및 원본 보존 검사
- preprocess_outfits_local.py:코디 전처리 기반 코드
- run_outfit2000_cached.py:기존 캐시를 이용한 2,000장 처리
- compare_outfit_missing200.py:상품→코디→유사상품 연결 비교
- auto_select_outfit200.py:후보 코디 자동 선별
- tag_personalize136.py:태그 기반 취향 정렬 실험

재실행 전 필요한 작업
1. 원본 연구 작업의 데이터·캐시·모델 폴더를 별도로 준비합니다.
2. 각 파일의 ROOT/REPO/MODEL 및 출력 경로를 확인합니다.
   원본 코드에는 작성자 PC 경로와 이전 팀 저장소 경로가 남아 있습니다.
   복사 위치를 기준으로 ROOT를 계산하는 코드도 있어 이 폴더에서 바로 실행하면 안 됩니다.
3. 팀의 해당 전처리 모듈과 기존에 사용한 Python/GPU 환경을 맞춥니다.
   PyTorch,Transformers,이미지 처리·Parquet 라이브러리 등은
   데모용 requirements.txt 범위에 포함하지 않았습니다.
   새 PC에서 연구 전체 파이프라인 재현은 검증하지 않았습니다.
4. 기존 산출물과 분리된 출력 경로를 사용하고 원본을 보존합니다.
   검증 코드가 사용하는 동결 해시와 비교 기준도 함께 확인합니다.

현재 저장소만으로 전체 전처리를 즉시 재현하는 실행 패키지는 아닙니다.
연구 환경 이식은 별도 작업이며, 본 패키지의 실행 안내는 로컬 옷장 데모 기준입니다.

기존 로컬 실행 기록 (이 패키지에서 다시 처리한 결과가 아님)
- 원본 코디 8,626장,기존 처리 2,000장 재사용
- 자동 후보 6,026장
- 외관 분류:성인 후보280장/아동 의심68장/불확실5,678장
- 외관 분류는 나이 확인이나 검수 완료 판정이 아닙니다.
  불확실 비율이 높아 이 결과를 그대로 시연 목록으로 교체하지 않았습니다.
- 원본 사진과 기존 특징값은 삭제하지 않았습니다.

사진·데이터·특징값·모델·실행 결과는 이 코드 폴더에 포함하지 않았습니다.
