# Stage 1 · Stage 2 공유 데이터 연결 결과

검증일: 2026-10-26. 데이터: multistage_data_v20261022. 모델: stage12-cvr-team-v20261022.

**업데이트 코드에 공식 데이터를 연결하고, CVR 기반 학습·추천 API 검증을 완료했다. 아래 네 가지 기준은 이번 고정 테스트셋에서 모두 통과했다.**

| 항목 | 목표 | 최종 Test 결과 | 판정 |
|---|---:|---:|---|
| 후보 Recall@300 | ≥ 0.30 | 0.300897 | 통과 |
| DeepFM CVR AUC | ≥ 0.70 | 0.721599 | 통과 |
| 후보 추출 시간 | < 100 ms | p95 1.338 ms | 통과 |
| 후보 수 | ≥ 300 | 측정 요청 모두 300개 | 통과 |

Recall은 기준을 약 0.0009 넘긴 근소한 통과다. 다른 시뮬레이션·분할에서도 같은 결과가 유지된다는 의미는 아니다. CTR은 학습하거나 평가하지 않았다.

## 측정 조건

- 상품 50,000개, 고객 10,000명, 공식 행동 로그 1,184,026건. 제공된 가격을 실제 모델 피처로 사용했다.
- 공식 Train/Valid/Test 분할 유지. Train으로 학습하고 Valid로 체크포인트를 선택했다. 두 모델 모두 5 epoch 중 5번째가 선택되었다. Two-Tower 검증은 고정 난수로 추출한 10,000개 조회, CVR 검증은 관찰 기간이 확보된 전체 Valid 조회를 사용했다.
- Test Recall은 유효 조회 **76,242건**에서 각각 정답 상품 1개가 후보 300개에 포함되는지 계산했다. 다중 구매 집합 Recall이 아닌 다음 조회 상품 기준 Recall/HitRate이다.
- CVR Test는 24시간 관찰 기간이 확보된 **68,005건**, 구매 전환 양성 **1,248건**이다. 로그손실은 0.091412.
- Valid 입력 이력은 Train, Test 입력 이력은 Train+Valid로 고정했다. Test의 이전 행동도 이력으로 넣지 않았다.
- 후보 시간은 CPU 4스레드, 워밍업 20회 후 200회 측정했다. 이력 조회·User Tower·FAISS를 포함하며 HTTP 통신과 모델 최초 로딩은 제외한다. p50 1.151 ms, 관측 최대 1.624 ms.
- 후보 검색+CVR 정렬 합계 p95는 2.917 ms. 운영 서버의 동시 접속·부하 시험은 수행하지 않았다.

## 연결 검증

- FastAPI 실제 앱 + 저장된 모델/인덱스로 `/api/recommend` 호출: HTTP 200.
- Uvicorn 로컬 서버를 직접 띄운 HTTP 요청도 200 및 추천 10개를 확인했다. 검증 후 서버를 종료했다. [HTTP 응답 기록](stage12_team_http.json).
- U00001, 2026-03-24T00:00:00+00:00, 상위 10개 반환. 모든 상품 ID가 공식 H&M 카탈로그에 존재하며 CVR 점수 내림차순, 중복 없음.
- 미등록 사용자도 HTTP 200로 기본 피처 추천. 이 동작이 신규 사용자 추천 품질을 보장하지는 않는다.
- 모델 검증 종료 전 시각의 추천 요청은 HTTP 400로 거부.
- 전체 테스트 **41개 통과**. 시점 누수·공개 입력·구매 귀속·신상품 제외·가입 전 행동 제외·학습/서빙 피처 일치·공식 분할·기존 검색/시뮬레이터 테스트 포함.
- Ruff 정적 검사 통과. Starlette TestClient의 httpx 사용 중단 예고 경고 1개가 있었으며 테스트 실패는 없다.

## 데이터 점검 및 제외

| 항목 | 처리 |

| 시각 경계를 넘는 Train/Valid 조회 | 총 42건 예제에서 제외; 원본 분할 재배정 없음 |

가입 전 행동은 원본 파일에서 삭제하지 않았다. 제외 목록은 모델 폴더의 `excluded_pre_signup_events.parquet`, 원본 파일 검증 기록은 `source_checksums.json`에 있다. 팀 시뮬레이터 담당자에게는 가입 시각 이전 세션 생성 여부를 확인할 필요가 있다.

## 완료 범위와 후속 작업

공식 공유 데이터의 배치 학습부터 추천 API까지 연결했다. Stage 1/2의 이번 CVR 오프라인 기준은 충족했다. 실시간 Redis 이력 갱신, Stage 3/MAB, CTR, 배포, GitHub 업로드는 별도 작업이다. `/api/events`로 새 행동을 전송해도 현재 저장 이력은 바뀌지 않는다.

평가 데이터는 시뮬레이터가 만든 데이터다. CVR AUC는 조회된 상품에 대한 평가이며 미조회 후보에서의 확률 정확도나 실제 구매율 향상을 입증하지 않는다. 시점별 가격 변경은 제공된 정적 카탈로그만으로 검증하지 못한다.
